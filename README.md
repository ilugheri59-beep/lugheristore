# LUGHERI STORE

Site responsivo de catálogo + carrinho + checkout pelo WhatsApp.

## Como cadastrar produtos
Abra `script.js` e preencha a lista `products`, por exemplo:

{ id: 1, name: "Camiseta", price: 59.90, category: "Camisas", image: "images/camiseta.jpg", description: "Descrição", featured: true }

Crie uma pasta `images` e coloque as fotos nela.
